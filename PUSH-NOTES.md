# Push notes

This repository was pushed from the Google AI Studio export of **TowerSpotter US**
on Oct 23, 2026, via the Muse GitHub connection.

**Not included in this push:** the 60 photo files in `src/assets/images/`
(about 53 MB of JPGs). The connection used for this push can only transfer
text files, so the images stayed behind. They exist in the original project
in Google AI Studio (TowerSpotter US) and in the exported ZIP
(`towerspotter-us.zip`). The code in `src/utils/towerImages.ts` refers to
those image files by name, so a fresh clone needs the images restored into
`src/assets/images/` before it will build and run exactly like the original.

Everything else from the export — all source code, data, and config — is
here, unchanged.
